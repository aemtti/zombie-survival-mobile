# Harrow Creek (mobile)

A single-file top-down zombie survival game: survive 10 minutes in a small town at night and reach the rescue helicopter.

This is the touch-screen edition: hold the phone sideways (the game turns itself if you hold it upright). Left thumb moves, right thumb aims and fires (drag past the ring), with buttons for reload, grenade, dash and weapon swap.

Everything (graphics and sound) is generated in code in `index.html`. The only outside resource is the Anton display font from Google Fonts.
