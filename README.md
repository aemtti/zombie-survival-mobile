# 해로 크릭 · Harrow Creek

밤이 오는 작은 마을에서 10분을 버티고 구조 헬기에 올라타는 탑다운 좀비 생존 게임입니다.
폰은 가로로 들고 왼손 엄지로 이동, 오른손 엄지로 조준·사격합니다(원 밖까지 끌면 발사). 대시·수류탄·장전·무기 교체는 버튼으로 합니다. PC에서는 WASD와 마우스로 합니다.

- 플레이: https://aemtti.github.io/zombie-survival-mobile/
- 기본 언어는 한국어입니다. 타이틀 화면 오른쪽 위나 일시 정지 메뉴의 **English** 버튼으로 영어로 바꿀 수 있고, 고른 언어는 기억됩니다.
- 그래픽과 소리는 모두 `index.html` 안의 코드로 만듭니다. 바깥에서 불러오는 것은 Google Fonts의 Anton(영문 제목)과 Black Han Sans(한글 제목) 글꼴뿐이며, 인터넷이 없으면 기기의 굵은 기본 글꼴로 대신 보입니다.
- 화면 오른쪽 아래 구석에 빌드 번호(예: `v1.1`)가 보입니다.

---

A top-down zombie survival game in a single HTML file: survive 10 minutes in a small town at night and reach the rescue helicopter.

On a phone, hold it sideways (the game turns itself if you hold it upright): the left thumb moves, the right thumb aims and fires (drag past the ring), and buttons handle dash, grenade, reload and weapon swap. On a computer, use WASD and the mouse.

- Play: https://aemtti.github.io/zombie-survival-mobile/
- The game starts in Korean. The **한국어 / English** button on the title screen (top right) or in the pause menu switches the language, and the choice is remembered.
- Everything (graphics and sound) is generated in code in `index.html`. The only outside resources are two Google Fonts: Anton (Latin headings) and Black Han Sans (Korean headings). Offline, headings fall back to the device's bold system fonts.
- The build number (for example `v1.1`) is shown in the bottom-right corner of the title screen.
